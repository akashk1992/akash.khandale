# Akash Khandale — Portfolio

An animated, responsive homepage built with Vite and Three.js.

## Run

`npm install` then `npm run dev`. Production build: `npm run build`.

## Personalize

Edit `site.config.js` to add your email, project titles, and public URLs. Until an email is supplied, the contact button opens your LinkedIn profile. Project links stay visibly marked as coming soon until supplied. Edit `index.html` for biography and project descriptions.

The 3D sculpture is generated in code, requires no external model assets, pauses outside the viewport, and respects reduced-motion preferences. Without WebGL, a static orbital illustration remains visible.
